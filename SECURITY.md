# Security Policy

## Supported Versions

Only the latest release / current main branch is actively maintained and receives security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

Marketing Engineers takes the security of this project seriously.

If you discover a security vulnerability or credential leak, please report it privately:

- **Email:** [security@marketingengineers.nl](mailto:security@marketingengineers.nl)
- Please provide a detailed description of the vulnerability, reproduction steps, and potential impact.
- We will acknowledge receipt of your report within 48 business hours and provide a timeline for remediation.

### Confidentiality Notice for Issue Reports

This application processes confidential meeting audio, client communications, and proprietary transcripts.

**DO NOT include any of the following in public GitHub Issues, Pull Requests, or public discussions:**
- Real audio recordings (`.m4a`, `.mp4`, `.wav`, `.flac`, etc.)
- Real transcription output or verbatim quotes from private meetings
- Real Google Cloud Storage bucket names or project identifiers
- Real service account keys, `.env` files, or OAuth tokens

When submitting bug reports or reproducing issues, always use synthetic test audio and generic placeholder names.
